## 実行結果

```text:Adjoint.hs
Sum {getSum = 11}
Sum {getSum = 11}
Sum {getSum = 26}
Sum {getSum = 26}
```

## 確認したこと

- **$a$ の側の自然性 `toMon (f . not) == h . map not` が成り立つ。**
  `not` で行先を入れ替えてから畳んでも、リストを `map not` してから
  `h = toMon f` で畳んでも `Sum 11` で一致する。
- **$m$ の側の自然性 `toMon (k . f) == k . h` が成り立つ。**
  要素ごとに 2 倍してから足しても、足してから 2 倍しても `Sum 26` で一致する。
  `k` が準同型（足し算を保つ）であることが効いている。
- **`toMon` は `foldMap` をリストと `Bool`・`Sum Int` に固定したもの。**
  `foldMap` は次節（`## 普遍性`）で導入するため、この節では前方参照を避けて
  `mempty` と `<>` による再帰で自前定義した。差し替えても結果は変わらない
  （`foldMap` 版でも同じ出力になることを確認済み）。
- **`Sum` の `Monoid` インスタンスは `Data.Monoid` の import だけで使える。**
  `mempty`・`<>` は `Prelude` にあるため追加の import は不要。
