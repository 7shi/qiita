# 辞書渡しの検証（記事「仕組み: 辞書渡し」の節）

GHC 9.6.6。実行は `runghc {ファイル名}`。

型クラスを使わずに、辞書（メソッドをまとめたレコード）を明示的に渡して
同じことをするコード。「`=>` の左側は実行時には `->` の引数になっている」ことを示す。

| ファイル | 内容 |
|---|---|
| `Dict.hs` | `Eq` を辞書で書き下す。`class`→レコード型、`instance`→レコードの値、`=>`→引数 |
| `DictMempty.hs` | `mempty` にあたる `emptyM` は辞書を渡すだけで値が出る（引数に型変数が不要な理由）|

## 実行結果

`Dict.hs`:

```
同じ
違う
```

`DictMempty.hs`:

```
""
"abcdef"
```

`emptyM dMonoidList` は値を一つも渡していないのに結果が得られる。
オブジェクト指向では値（オブジェクト）が実装表を持ち歩くため、これができない。

なお実際の GHC は最適化で辞書渡しを消すことが多い（型が具体的に分かる箇所は
特殊化して直接呼び出しにする）。あくまで意味論としての説明。
